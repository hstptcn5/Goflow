# DailyOps Beta Limitations

- The Windows AMD64 candidate is unsigned pilot software. SmartScreen or
  organizational policy can block it.
- There is no installer, auto-update, Release channel, marketplace, production
  signing, hosted control plane, or default remote telemetry.
- Updates are explicit offline operations. Keep rollback copies until manual,
  scheduled, and restart checks pass.
- DailyOps accepts the documented normalized HTTP(S) JSON contract and sends a
  Telegram report. It is not a claim of compatibility with KiotViet, Sapo,
  Haravan, or another store vendor.
- The service is loopback-only and intended for one local Windows user and one
  managed DailyOps appliance.
- The current artifact and automated loopback evidence do not prove customer
  validation, commercial demand, willingness to pay, production readiness, or
  production security governance.
- Production publisher identity, signing-key custody, rotation/revocation,
  minimum-version policy, and certificate authority remain external gates.
- A real nontechnical pilot and an approved vendor/sandbox decision remain
  manual gates after review and merge.
